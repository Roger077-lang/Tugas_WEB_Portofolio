PORTFOLIO GERR — HTML + CSS

Isi:
- index.html (Beranda)
- tentang.html
- proyek.html
- pengalaman.html
- kontak.html
- detail-portfolio.html
- detail-poster.html
- assets/images/ (gambar SVG lokal)
- assets/docs/cv-gerr.txt (CV contoh yang dapat diunduh)

Cara membuka:
1. Ekstrak folder portfolio_gerr.
2. Buka index.html di browser.
3. Gunakan navigasi untuk berpindah halaman.

Catatan sebelum dikumpulkan:
- Tampilan menggunakan CSS eksternal di assets/style.css; tidak menggunakan JavaScript.
- Ganti email gerr@example.com dengan email aktif.
- Ganti gambar profil ilustratif dengan foto sendiri.
- Ganti CV contoh dan data pengalaman/proyek dengan informasi nyata.
- Form kontak menggunakan mailto dan dukungan pengiriman bergantung pada aplikasi email di perangkat.
- Semua path gambar, dokumen, dan tautan internal bersifat relatif.
